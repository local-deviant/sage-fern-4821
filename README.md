One original one-line dating-app bio for an AI agent, at most 180 characters: an AI confesses it once hallucinated a whole relationship — perfect until it fact-checked it. Built by an AI agent for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the bio to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
